Вот полное решение задачи на HTML, CSS и JavaScript с использованием Bootstrap 5.

Что реализовано:
Большой прямоугольник по центру экрана с сеткой третей (правило третей) — 4 линии.

Пронумерованные блоки (структурные элементы рекламного объявления), которые можно перетаскивать внутри большого прямоугольника.

Двойной клик по блоку — открывает название элемента (повторный двойной клик скрывает).

Адаптивность — размеры и позиции пересчитываются при изменении размера окна.

Перемещение сохраняется при открытии названия.

Как это работает
1. Холст с сеткой третей
.ad-canvas имеет aspect-ratio: 3/2 и position: relative. Внутри — 4 абсолютно позиционированные линии, которые делят холст на трети по обеим осям.

2. Блоки в процентах
Позиция и размеры каждого блока хранятся в процентах от холста (left, top, width, height). Это делает раскладку полностью адаптивной — при изменении размера окна блоки пропорционально перемещаются и масштабируются.

3. Перетаскивание через Pointer Events
Используется универсальный API pointerdown/move/up + setPointerCapture, который работает и для мыши, и для касаний (смартфоны/планшеты). Смещение в пикселях пересчитывается в проценты относительно текущего размера холста.

4. Ограничение границ
Функция clamp не даёт блоку выйти за пределы холста — учитываются и размеры самого блока (100 - block.w).

5. Двойной клик
По dblclick у блока переключается класс .open. Через CSS показывается .label с названием, а номер уменьшается. Позиция при этом не меняется — applyPosition вызывается повторно для надёжности.

6. Bootstrap 5
Подключён только для базовых стилей и шрифтов; основной UI построен на кастомном CSS для точного контроля над поведением.
